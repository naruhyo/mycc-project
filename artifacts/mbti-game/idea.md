# MBTI 캐릭터 매치

## Problem Statement

**HMW** — 지루한 설문 없이, 선택하는 재미만으로 '나'를 드러내고 → 그 결과로 "내가 어떤 캐릭터와 닮았는지"까지 보여주는 2분짜리 공유 가능한 경험을 만들 수 있을까?

(틀 변경: *MBTI를 정확히 측정* → *재미있고 공유하고 싶은 2분짜리 정체성 경험*. MBTI는 수단, 캐릭터 매칭이 페이오프.)

## Recommended Direction

**시나리오 선택형 MBTI 게임 + 닮은 캐릭터 결과 카드.** 일상·상황 시나리오 12~16개를 제시하고 사용자가 2~4개 선택지에서 행동을 고른다. 각 선택은 4차원(E/I, S/N, T/F, J/P) 점수에 가중치를 더해 16유형 중 하나를 판정한다. 결과 화면은 유형명·짧은 성격 설명·**닮은 캐릭터 3명**(이름·출처·한 줄 코멘트)을 카드 형태로 보여주고 "다시하기" + "결과 링크 복사"를 제공한다.

이 방향을 추천하는 이유: (1) Netflix 공식 콘텐츠 API가 없다는 제약을 "캐릭터"로 우회하면 데이터는 전부 정적 큐레이션으로 끝난다. (2) 캐릭터 매칭은 검증된 바이럴 포맷이고(Buzzfeed류), MBTI 결과보다 공유 욕구를 훨씬 자극한다. (3) 기존 스택(Next.js 16 + React 19 + shadcn + Tailwind 4)만으로 외부 의존 없이 완결된다.

진짜 차별점은 **캐릭터 풀의 선택**(애니/영화/드라마/혼합)과 **결과 카드의 시각적 완성도**다. 시나리오 작문 품질이 신뢰감을 좌우하므로 큐레이션 시간을 충분히 잡아야 한다.

## Key Assumptions to Validate

- [ ] **12~16개 시나리오 질문으로 16유형을 그럴듯하게 판정 가능하다** — 검증: 본인·지인 5명에게 테스트 → 자가진단 MBTI와 결과가 60%+ 일치하는지 확인
- [ ] **16유형 × 3명 = 48명 분량의 캐릭터 큐레이션이 일관성 있게 가능하다** — 검증: spec 단계에서 캐릭터 풀(예: "글로벌 애니 + 한국 드라마") 정의 후 16유형 중 5개 유형을 먼저 큐레이션해 품질 확인
- [ ] **결과 화면 캡처가 공유 욕구를 자극할 만큼 시각적으로 매력적이다** — 검증: wireframe → 디자인 시안 단계에서 5명에게 "이거 친구한테 보낼 의향?" 질문

## MVP Scope

**포함**
- 12~16개 시나리오 질문 (4차원 × 3~4문항)
- 4차원 점수 계산 → 16유형 판정 로직
- 16유형 각각의 결과 화면: 유형명 + 짧은 성격 설명(2~3문장) + 닮은 캐릭터 3명 카드
- "다시하기" + "결과 링크 복사" 액션
- 모바일 우선 단일 페이지 흐름 (질문 → 결과)

**제외 (MVP 외)**
- 사용자 계정·결과 저장
- 결과 이미지 다운로드/SNS 직접 공유 버튼
- 다국어 (한국어 단일)
- 외부 API 연동
- 깊이 있는 성격 분석 리포트

## Not Doing (and Why)

- **정확한 MBTI 측정** — 가벼움·공유 우선이라 정확도는 목표가 아님. 12~16문항으로 충분히 "그럴듯한" 결과면 된다.
- **외부 콘텐츠 API (Netflix/TMDB)** — 정적 큐레이션이 더 빠르고, 안정적이고, MVP 가설 검증에 충분.
- **사용자 계정/이력 저장** — 1회성 경험이라 불필요한 마찰. 결과는 URL 파라미터로 공유.
- **이미지 카드 다운로드 기능** — 구현 비용 대비 MVP에서 검증할 가설과 무관. 공유율 가설 검증 후 추가 고려.
- **16유형 + 궁합/조합** — 한 가지 페이오프(닮은 캐릭터)에 집중. 산만한 결과 화면은 공유율을 떨어뜨림.

## Open Questions

- **캐릭터 풀** — 애니 / 한국 드라마 / 해외 영화 / 혼합 중 어느 풀로 큐레이션할 것인가? (이미지 사용 권한도 고려: 공식 이미지 vs 이름·작품명 텍스트만)
- **시나리오 작문 톤** — 일상적 상황(친구·연인·직장) vs 판타지·모험 상황 중 어떤 톤이 타깃과 잘 맞는가?
- **디자인 톤** — 파스텔·일러스트형(귀여움) vs 시네마틱·다크형(세련됨) 중 캐릭터 매칭과 어울리는 무드는?

→ 위 3개 질문은 `/write-spec` 또는 `/sketch-wireframe` 단계에서 확정.
