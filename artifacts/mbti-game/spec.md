# MBTI 캐릭터 매치

## 개요

12개의 일상 시나리오에 답하면 4차원(E/I, S/N, T/F, J/P) 점수를 합산해 16유형 중 하나로 판정하고, 그 유형과 닮은 글로벌 애니/만화 캐릭터 3명을 카드로 보여주는 2분짜리 모바일 우선 단일 페이지 경험. 결과는 URL 링크로 친구에게 공유한다.

## 범위

### 포함

- 시작 화면 (제목 + "시작하기" 버튼)
- 12개의 시나리오 질문 (각 2~4개 선택지)
- 진행 상태 표시 (현재 N / 12)
- 12문항 응답 후 16유형 중 하나 판정
- 결과 화면: 유형 코드(예: ENFP), 한 줄 별명, 2~3문장 성격 설명, 닮은 캐릭터 3명 카드
- "다시하기" 버튼 → 시작 화면으로
- "링크 복사" 버튼 → 클립보드에 `?type=XXXX` URL 복사 + 복사됨 피드백
- `?type=XXXX` URL 직접 진입 시 결과 화면 즉시 표시 + "나도 해보기" CTA
- 모바일(360px ~) 우선, 데스크톱은 가운데 정렬 + 너비 제한
- 한국어 단일 언어

### 제외

- **사용자 계정·결과 영구 저장** — 1회성 경험. 결과는 URL로 공유.
- **이미지·일러스트** — 저작권 검토 시간 + 자산 큐레이션 시간 절약. 텍스트 카드만.
- **이미지 다운로드/SNS 직접 공유 버튼** — 링크 복사만으로 가설 검증 가능.
- **중간 진행 저장(localStorage)** — 2분짜리 경험이라 이탈 시 비용 낮음. 구현 단순화.
- **결과 깊은 분석(궁합·조합)** — 캐릭터 매칭 단일 페이오프에 집중.
- **다크 모드 토글 UI** — 라이트 단일.
- **다국어** — 한국어만.
- **잘못된 type 파라미터 에러 화면** — 16유형 화이트리스트가 아니면 시작 화면으로 fallback.

## 시나리오

### 1. 처음 방문 → 결과까지 완주

- **Given** — `?type` 파라미터가 없는 URL로 접속한 사용자
- **When** — "시작하기" 클릭 → 12개 질문에 순서대로 답함
- **Then** — 12번째 답 직후 결과 화면이 표시되고 유형 코드(예: "ENFP"), 별명, 2~3문장 설명, 캐릭터 카드 3개가 보인다

성공 기준:
- [ ] 시작 화면에 "MBTI 캐릭터 매치" 제목과 "시작하기" 버튼이 보인다
- [ ] "시작하기" 클릭 → 1번 질문이 보이고, 진행 표시 "1 / 12"가 보인다
- [ ] 각 질문에서 선택지 클릭 → 다음 질문으로 진행, 진행 표시 숫자 증가
- [ ] 12번째 선택지 클릭 → 결과 화면 전환, 유형 코드 4글자 텍스트(E/I + S/N + T/F + J/P)가 보인다
- [ ] 결과 화면에 캐릭터 카드 정확히 3개가 렌더된다
- [ ] 각 캐릭터 카드에 이름, 작품명, 한 줄 코멘트 텍스트가 모두 보인다

### 2. 결과 공유 — 링크 복사

- **Given** — 결과 화면(예: ENFP)을 보고 있는 사용자
- **When** — "링크 복사" 버튼 클릭
- **Then** — 클립보드에 `<현재 origin>/?type=ENFP` 형식의 URL이 복사되고, "링크가 복사되었습니다" 피드백이 잠시 보인다

성공 기준:
- [ ] "링크 복사" 버튼 클릭 → 클립보드 내용이 `?type=<유형코드>`로 끝나는 URL
- [ ] 클릭 직후 "복사됨" 같은 피드백 텍스트가 나타난다 (2초 이내 사라지거나 유지)

### 3. 공유 링크로 진입한 친구

- **Given** — 공유받은 `?type=ENFP` URL을 처음 클릭한 사용자
- **When** — 페이지 로드
- **Then** — 시작 화면이 아닌 ENFP 결과 화면이 바로 표시되고, 화면에 "나도 해보기" CTA가 보인다

성공 기준:
- [ ] `?type=ENFP` URL 진입 → 유형 코드 "ENFP"가 보인다
- [ ] 결과 화면 안에 "나도 해보기" (또는 동등한 의미의) 버튼이 보인다
- [ ] "나도 해보기" 클릭 → 시작 화면으로 전환되고 1번 질문 진입 가능

### 4. 다시하기

- **Given** — 결과 화면을 보고 있는 사용자
- **When** — "다시하기" 버튼 클릭
- **Then** — 시작 화면으로 돌아가고, 이전 응답은 사라진다

성공 기준:
- [ ] "다시하기" 클릭 → 시작 화면("시작하기" 버튼이 보이는 화면)이 나타난다
- [ ] 이어서 다시 진행하면 1번 질문부터 시작된다 (진행 표시 "1 / 12")

### 5. 중간 새로고침

- **Given** — 12문항 중 5번째 질문에 답하고 있는 사용자
- **When** — 브라우저 새로고침
- **Then** — 시작 화면으로 돌아간다 (진행 손실)

성공 기준:
- [ ] 5번째 질문 화면 → 새로고침 → 시작 화면이 표시된다 (5번 질문이 아님)
- [ ] 다시 시작하면 1번 질문부터 진행한다

### 6. 잘못된 type 파라미터

- **Given** — 16유형 코드가 아닌 `?type=XYZ` URL로 접속
- **When** — 페이지 로드
- **Then** — 시작 화면이 표시된다 (에러 화면 없음)

성공 기준:
- [ ] `?type=XYZ`, `?type=enfp`(소문자), `?type=`(빈 값) 등 화이트리스트 외 값 → 시작 화면 표시
- [ ] 콘솔에 에러를 띄우지 않는다 (조용한 fallback)

### 7. 점수 동점 처리

- **Given** — 12문항을 답한 결과 4차원 중 하나 이상이 정확히 동점
- **When** — 결과 판정 시점
- **Then** — 항상 16유형 중 정확히 하나의 유형 코드가 결정된다

성공 기준:
- [ ] 모든 차원이 동점인 입력(예: 모두 중립 선택) → 결과 화면이 정상 표시되고, 유형 코드가 16개 중 하나
- [ ] 동일 입력은 항상 동일 유형으로 판정된다 (결정적)

## 불변 규칙

- **결정성**: 동일한 12개 응답은 항상 동일한 유형 코드를 만든다. 랜덤 요소 없음.
- **결과의 완결성**: 결과 화면은 유형 코드, 별명, 설명, 캐릭터 카드 3개가 모두 채워져 렌더된다. 16유형 어느 결과로 들어와도 빈 칸이 없다.
- **외부 의존 없음**: 어떤 시나리오도 외부 API, 외부 이미지 호스트, 외부 폰트(시스템/번들 외)에 의존하지 않는다. 오프라인에서도 동작한다.
- **모바일 우선**: 모든 화면이 360px 폭에서 가로 스크롤 없이 보인다. 텍스트 잘림 없음.
- **빠른 응답**: 선택지 클릭 → 다음 질문 표시까지 체감 즉시(<100ms). 네트워크 호출 없음.
