12개 문항을 순차적으로 보여준다. 선택지를 누르면 즉시 다음 문항으로 넘어가고 진행 표시가 갱신된다.

  • 트리거: 시작 화면 "시작하기" 클릭 직후
  • 인터랙션: 선택지 A/B/C/D 중 하나 클릭 → 즉시 다음 질문으로 전환 (체감 100ms 이내)
  • 전환: 12번째 선택지 클릭 → 결과 화면 / 새로고침 → 시작 화면 (진행 손실)
  • 시나리오 5: 5/12 상태에서 새로고침하면 시작 화면으로 돌아간다 (사용자 검증 포인트)

Notes

최종 페이오프 화면. 유형/별명/설명/캐릭터 3개가 항상 채워진다 (불변 규칙: 결과의 완결성).

  • 트리거: 12번째 답변 직후 / ?type=XXXX URL 진입
  • 인터랙션 (자가 완료): "링크 복사" → 클립보드에 현재origin/?type=ENFP 복사 + 토스트 / "다시하기" → 시작 화면
  • 인터랙션 (공유 진입): "나도 해보기" → 시작 화면 (1번 질문 진입 가능) / "링크 복사"는 동일하게 동작
  • 전환: 다시하기·나도 해보기 → 시작 화면 / 토스트 자동 사라짐 (~2초)
  • 시나리오 7 (동점): 같은 결과 화면이지만 모든 차원 동점 입력에도 16유형 중 하나로 결정적 판정
  • 캐릭터 카드: 이모지 시그니처 3개 + 카드별 액센트 컬러(피치/라벤더/버터). 저작권 0, 캐릭터 즉시 연상 (spec 제외 항목 '이미지'는 그대로 유지 — 이모지는 시스템 폰트라 별도 자산 없음)
